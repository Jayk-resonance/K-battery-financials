## 검토 대기 85행

### 유진투자증권 50행

- 2022~2025년 연간 과거 실적 데이터
- EV 42행 / ESS 8행
- 단위: 천대 35행 / GWh 9행 / % 6행
- 출처: PDF 6, 11, 12, 36, 45~49, 60쪽
- 현재 `metric=실적치`로 저장되어 실제 지표가 판매대수·설치에너지·수요량·침투율
  중 무엇인지 자동 판정하지 못했다.

이 50행은 연간 시장 데이터 범위에 들어올 가능성이 높다. 신규 P1 페이지를 보기 전에
원문 표의 행·열 제목으로 실제 지표를 확정해야 한다. 특히 60쪽 한 페이지에 33행이
모여 있어 페이지 단위로 확인하면 행 단위 검토보다 효율적이다.

### 하나증권 35행

- 전부 2026년 월간 또는 연초 누적(YTD) 데이터
- EV 30행 / ESS 5행
- 출처: PDF 1, 2, 8, 9, 10, 15쪽
- 현재 `FY`로 저장하면 월간·누적 값을 연간 값으로 오인하게 되므로 자동 이관을
  차단한 상태가 맞다.

이 35행은 우선 연간 시장 데이터 백필 대상에서 보류한다. 향후 월간·YTD 시계열까지
수집하기로 결정할 때 `period`를 별도로 정의한 뒤 이관한다.

## 수동 보강 중복 10건

유진투자증권의 수동 보강 18행 중 다음 10행은 자동 이관행과 시장·지역·지표·연도·값·
단위가 동일하다.

- 글로벌 BESS 신규 설치 2026~2030년: 5행
- 유럽 BESS 신규 설치 2026~2030년: 5행

PDF를 화면으로 확인한 결과 동일 전망치가 요약 페이지와 상세 페이지에 반복되어 있었다.

- 글로벌 BESS: PDF 6쪽 요약과 9쪽 상세
- 유럽 BESS: PDF 11쪽 요약과 14쪽 상세

두 페이지 번호 모두 원문상 맞지만 동일 시계열을 두 번 표시하면 집계 시 이중 계산될 수
있다. 상세 페이지를 근거로 만든 수동 보강행을 유지하고 자동 이관행을 대체하는 것이
적절하다.

수동 보강행 12개에 기존 `legacy_row`를 연결해 다음을 함께 해결했다.

- 2026~2030년 중복 market 행 10개 제거
- 2025년 글로벌·유럽 BESS 실적 2개를 검토 대기열에서 정식 market 행으로 대체
- 유진 최종 market 행: 145 → 135
- 유진 검토 대기: 50 → 48
- 두 리포트 합계: market 142행 / 검토 대기 83행

대상 legacy row는 글로벌 100~105번, 유럽 118~123번이다.

## P1 후보와 기존 검토 대기 페이지 관계

기존 이관 검토 페이지와 새 P1 후보 페이지는 겹치지 않는다.

- 유진 P1 후보: 4, 15, 18, 37쪽
- 유진 기존 검토: 6, 11, 12, 36, 45~49, 60쪽
- 하나 P1 후보: 3, 6, 7, 13쪽
- 하나 기존 검토: 1, 2, 8, 9, 10, 15쪽

따라서 P1 후보 8페이지를 바로 백필하면 기존 검토 대기 85행과 의미상 중복되거나,
과거 실적 시계열이 미완성인 상태를 놓칠 수 있다. 기존 이관 정리가 먼저다.

## P1 백필 전 통과 조건

1. 유진 수동 보강 12행에 `legacy_row`를 연결해 의미상 중복 10건을 제거한다.
2. 같은 report ID 안에서 의미 차원이 같은 행을 탐지하는 검증을 추가한다.
3. 유진 과거 연간 실적 50행을 실제 지표별로 판정한다.
4. 하나 월간·YTD 35행은 연간 데이터에서 계속 보류한다.
5. 인덱스를 재생성해 market 142행, 검토 대기 83행, 의미상 중복 0건인지 확인한다.

이 다섯 조건을 통과한 뒤에만 P1 산업 후보 8페이지의 신규 백필을 시작한다.

## 정리 완료 결과

다섯 조건을 모두 통과했다.

- 수동 보강 12행과 legacy row 연결 완료
- 선정 산업리포트 2건: market 142행 / 검토 대기 83행
- 2026년 이후 동일 report ID 의미상 중복: 0건
- 전체 market 인덱스: 837행 → 827행
- 전체 review 인덱스: 529행 → 527행
- 기존 경고: 1,855건으로 증가 없음
- 전체 unittest: 46개 통과

유진 과거 실적 50행의 실제 지표는 판매대수 35행, 침투율 6행,
설치에너지 3행, 수요량 6행으로 판정했다. 이 중 글로벌·유럽 BESS 설치에너지
2행은 정식 market 행으로 대체했고, 나머지 48행은 지표 판정 이력을 남긴 채
검토 대기 상태를 유지했다.

하나 35행은 판매대수 27행, 설치에너지 5행, 성장률 2행, 수요량 1행으로
지표를 판정했지만 모두 월간 또는 YTD이므로 연간 인덱스 보류를 유지했다.
판정과 보류 이력은 `market_series_review_decisions.json`에 영구 보존하며,
재생성된 `market_series_review.csv`에도 함께 표시한다.

이번 정리에서는 P1 산업 후보 8페이지의 신규 백필을 시작하지 않았다. 다음 단계부터
해당 8페이지를 기존 142행과 대조하면서 신규 데이터만 선별할 수 있다.
