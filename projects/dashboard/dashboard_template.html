K-배터리 리포트 인텔리전스

표시 단위는 억원(축 레이블만 1조 이상 시 조 병기), 주가는 만원. 모든 영업이익 비교는 AMPC 포함 기준으로 통일합니다. AMPC 제외값만 공시한 리포트는 동일 리포트의 AMPC를 더해 비교 가능한 값으로 환산합니다. LGES 매출은 1Q26부터 AMPC 병합 표시(회사 IR 재작성 기준)이며 3사 매출 비교는 AMPC 제외 기준을 기본으로 사용합니다. 데이터 출처: 증권사 리포트(상단 표시 건수, 기업+산업) + 3사 회사 IR. 기업 분석 탭(②③⑤)은 기업 리포트만 사용하며 산업리포트는 ⑥탭(및 과거 추정 오차의 빈티지 분석, 출처 표기) 전용입니다. 모든 수치는 원문 페이지로 역추적 가능(battery-reports DB). 이 도구는 내부 분석용이며 투자 권유가 아닙니다.
